## 화면별 기능

| 화면 | 주요 기능 | 데이터·동작 |
| --- | --- | --- |
| 대시보드 | 매장 요약, 플랫폼 연결 상태, 설정 안내 | 현재 선택 매장의 데이터와 로그인 확인 상태 표시 |
| 매장 관리 | 매장 추가·삭제, 메뉴·가격, 공식 매장 정보, 플랫폼 계정 주소 | 매장별 SQLite 저장. 마지막 남은 매장은 삭제 제한 |
| 콘텐츠 작성 | 플랫폼별 제목·본문, 다중 초안, 복제·보관·삭제·버전 복원 | 약 700ms 뒤 자동 저장. 문서별 버전 최대 50개 |
| GPT 검토 | 4개 플랫폼 생성, 개별 재질문, 직접 수정·선택 적용 | 생성 답안을 검토 상태로 보관. 적용 후 편집 원고에 반영 |
| 게시 미리보기 | 원고·사진 확인, 대상 선택, 사전 점검, Instagram 위치 검색어 | 최종 게시 전 입력할 내용을 검토 |
| 게시 이력 | 입력 성공 기록 조회 | 외부 게시 완료 확인 이력과는 구분 |
| 작업 이력 | 작업 번호, 플랫폼별 성공·실패, 상세 사유, 게시물 URL | 플랫폼 처리 직후 결과 저장. 페이지당 20건 조회 |
| 설정 | 플랫폼 활성화, 이미지 용량·정리, 백업·복원 | SQLite·이미지 통합 백업. 로그인 프로필·API 키 제외 |

매장 관리의 빠른 템플릿은 세션 미리보기이며 영구 저장이나 콘텐츠 작성 연동을 제공하지 않습니다.

## 플랫폼별 게시 준비

| 플랫폼 | 앱이 준비하는 내용 | 사용자가 완료하는 단계 |
| --- | --- | --- |
| 네이버 블로그 | 글쓰기 진입, 제목·섹션별 사진·본문 입력, 배치 검증, 장소 검색 | 장소 선택·추가·확인과 최종 발행 |
| Instagram | 게시물 작성 화면, 이미지, 캡션, 위치 검색 | 최종 확인과 공유 |
| Threads | 작성 모달, 본문과 이미지 | 필요한 주제 선택과 최종 게시 |
| 당근 소식 | 비즈프로필 소식 제목·본문·이미지 | 기존 작성물 처리 선택과 등록 |

활성화한 플랫폼 중 이번 작업에서 선택한 대상을 **네이버 → Threads → 당근 → Instagram** 순으로 처리합니다. 조건 미충족과 입력 오류는 실패 사유로 기록하고 다음 대상으로 이동합니다. Threads 여러 게시물을 연결하는 체인 기능은 없습니다.

## GPT 작성 흐름

1. 매장 정보·메뉴·가격과 작성 요청을 수집합니다.
2. 플랫폼별 저장 예시를 최대 3개까지 말투 기준으로 전달합니다.
3. Responses API와 엄격한 JSON 스키마로 플랫폼별 답안을 생성합니다.
4. 저장된 공식 매장 정보 블록을 프로그램에서 추가합니다.
5. 사용자가 검토창에서 수정하거나 해당 플랫폼만 다시 질문합니다.
6. 선택한 답안을 실제 원고에 적용합니다.

이미지 픽셀 분석, 예시 원고의 사실성 보장, 생성 문장의 사실 검증 기능은 포함하지 않습니다. 이미지 ID·이름·설명·선택 순서만 전달하고, 메뉴·가격 등 생성 결과의 최종 확인은 사용자가 진행합니다.

## 이미지·초안 관리

- 업로드: 한 번에 1~10개, 파일당 최대 10MB, 요청 전체 최대 100MB.
- 파일 검사: JPG·PNG·WEBP·GIF의 MIME 및 파일 시그니처 확인.
- 중복 방지: SHA-256 기반 파일명으로 동일 매장 내 같은 파일 중복 저장 방지.
- 선택: 매장별 보관함 최대 100장, 플랫폼별 선택 최대 10장.
- 정리: 초안뿐 아니라 보관된 버전의 이미지 참조도 확인해 미사용 파일을 분리.
- 복원: 첫 변경과 이후 5분 간격으로 변경 전 상태 보관, 복원 직전 현재 내용도 저장.

위 수치는 앱 내부 제한이며 각 플랫폼의 실제 허용 조건과는 다를 수 있습니다.

## 사전 점검과 알림

게시 전 필수 제목·본문, 이미지 참조, 이미지 수와 글자 수를 점검합니다. 가격·주소의 사실 검증이나 금칙어 판정은 자동 점검에 포함되지 않습니다.

게시 준비 알림은 앱이 실행 중일 때 30초 간격으로 예약 시각을 확인합니다. 앱 알림과 권한이 허용된 데스크톱 알림을 표시하며, 자동 입력이나 게시를 실행하지 않습니다.

## 확장할 수 있는 부분

- 작업 실행을 서버에서 지속 관리하고 실패 지점부터 재개하는 UI.
- 실제 게시 완료 감지와 게시물 조회.
- 이미지 편집과 플랫폼 비율별 자르기.
- 빠른 템플릿의 영구 저장·작성 화면 연동.
- 예약 자동 백업과 외부 내보내기.

현재 구현 기능과 구분해 기재한 확장 항목입니다.
